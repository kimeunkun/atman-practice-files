# ATMAN STUDIO 강의 실습 파일

ATMAN STUDIO 유튜브 강의에서 쓰는 실습 파일을 여기서 받을 수 있습니다.

## 받는 법

- 강의 영상 **설명란의 다운로드 링크**를 누르면 바로 받아집니다.
- 직접 찾으려면 이 페이지 오른쪽의 **Releases**에서 강의 이름을 고른 뒤 `.zip` 파일을 받으세요.
- 필요한 프로그램 버전은 릴리스마다 적어 둡니다.

## 시리즈

| 재생목록 | 실습 파일 |
|---|---|
| [애프터이펙트 기초 강의 (무료 13강)](https://www.youtube.com/playlist?list=PLKfTMJ5_6OeE) | 준비 중 |
| 애프터이펙트 심화 | 준비 중 |

## 이용 안내

- 개인 학습과 수업 실습에는 자유롭게 쓰셔도 됩니다.
- 파일 자체를 다른 곳에 다시 올리거나 판매하는 것은 안 됩니다.
- 영상 강의는 [ATMAN STUDIO 유튜브 채널](https://www.youtube.com/channel/UClazfQQbEY032qd2MUA31Qw)에서 볼 수 있습니다.
